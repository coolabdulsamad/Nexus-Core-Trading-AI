View Dashboard on Your Phone (No Deploy Needed)
1
Find your computer's local IP
Linux/Mac: open Terminal → ip addr or ifconfig → look for 192.168.x.x
Windows: open CMD → ipconfig → find IPv4 Address
2
Serve this HTML file on a local server
Navigate to the folder containing dashboard.html, then run:
python3 -m http.server 8080
(or if Python 2: python -m SimpleHTTPServer 8080)
3
Open on your phone
Make sure your phone is on the same Wi-Fi network. Open your phone's browser and go to:
http://<YOUR-IP>:8080/dashboard.html
e.g. http://192.168.1.42:8080/dashboard.html
4
Set the log file URL
In Settings → Log URL, enter the full path visible to the Python server, e.g.:
http://192.168.1.42:8080/live_trader_multi.log
(place the log file in the same folder you ran the server from, or use a symlink)
5
Optional: auto-refresh on mobile
The dashboard already polls every 5s by default. You can change the interval in Settings. Add to your phone's Home Screen for a full-screen app-like experience.
Your phone and computer must be on the same local network (same Wi-Fi router). This works without any internet deployment.
